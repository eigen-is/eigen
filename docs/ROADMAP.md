# Roadmap

Prioritized backlog of the work still to do on **the road to a trustworthy 1.0**. Eigen runs in production but is honest about being pre-1.0, so the data-integrity work comes first. The P3 deferrals and everything else that waits until after 1.0 (or until a trigger appears) live in [ROADMAP-POST-1.md](ROADMAP-POST-1.md). Status is what exists today, not what the proposal hoped for; the detailed designs live in the `docs/proposals/PROPOSAL_*.md` files referenced per row.

Eigen does not implement backward compatibility for persisted formats before 1.0: a format-breaking change is done outright now (existing data is dropped, or converted with a one-off), and a migration system becomes mandatory only from 1.0. Stickies are the exception: eigen.is users rely on them, so stickies data stays backward compatible now. No pre-1.0 item left on this page breaks a persisted format; the remaining format breaks live in [ROADMAP-POST-1.md](ROADMAP-POST-1.md).

A grant application (NLnet Restack, call opens 2026-09-03, deadline 2026-11-03) funds the data-integrity push; the funding and launch tactics themselves are tracked separately in `docs/superpowers/strategy/` (local-only) and are not duplicated here.

The current focus, ahead of announcing the open-source repository, is the self-hoster's path: install, update, whole-server backup and a mail-off install. What is left of it is the restore drill in the Docker-only install row, and the Light restore row in P0, which blocks 0.3.2.

**Legend**: Effort: S / M / L / XL (rough T-shirt size). Frozen-format: pre-1.0 the column flags a change to a persisted format (Yjs roots, DB schema, drive MIME values) that drops or converts existing data when done.
