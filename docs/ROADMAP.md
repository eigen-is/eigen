# Roadmap

Prioritized backlog of the open work on **the road to a trustworthy 1.0**. Eigen runs in production but is honest about being pre-1.0, so the data-integrity work comes first. The P3 deferrals and everything else that waits until after 1.0 (or until a trigger appears) live in [ROADMAP-POST-1.md](ROADMAP-POST-1.md). Status is what exists today, not what the proposal hoped for; the detailed designs live in the `docs/proposals/PROPOSAL_*.md` files referenced per row. Last pruned 2026-09-15.

Eigen does not implement backward compatibility for persisted formats before 1.0: a format-breaking change is done outright now (existing data is dropped, or converted with a one-off), and a migration system becomes mandatory only from 1.0. One planned pre-1.0 item breaks a persisted format: calendar events move to `.ics` files (P1), which drops existing calendar data by decision. The remaining format breaks live in [ROADMAP-POST-1.md](ROADMAP-POST-1.md).

A grant application (NLnet Restack, call opens 2026-09-03, deadline 2026-11-03) funds the data-integrity push; the funding and launch tactics themselves are tracked separately in `docs/superpowers/strategy/` (local-only) and are not duplicated here.

**Legend** — Effort: S / M / L / XL (rough T-shirt size). Frozen-format: pre-1.0 the column flags a change to a persisted format (Yjs roots, DB schema, drive MIME values) that drops or converts existing data when done.
