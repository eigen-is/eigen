eigen|docs⟩ is the word processor in Eigen. You write on a page, and it saves as you type, so there is no Save button. Other people can write in the same document at the same time ([Get started](/support/docs/get-started)).

::: video src="/data/about/media/docs-hero" caption="A line added to the production plan, and undo takes it back."
:::

## Writing together

Share a document with people, a team or a link ([Share a document and set access](/support/docs/share-a-document)). Everyone with edit access can type in it at the same time, and you see their cursor with their name on it ([Get started](/support/docs/get-started)). Save a version before a big rewrite, and you can roll back to it later ([Restore a previous version of a document](/support/docs/doc-versions)).

::: video src="/data/about/media/docs-collab-pair" caption="Nour answers the crew shortage on the right; Saar sees it arrive on the left."
:::

## Comments

Select a passage and add a comment. It gets a highlight and its own thread, where people reply, @mention each other and resolve it when it is done. Rest your mouse on a highlight and the comment shows without opening anything ([Comment and discuss](/support/docs/comments)).

## More than text

There are tables, images and charts ([Insert images, charts, and tables](/support/docs/images-and-tables)), headers with page numbers ([Add headers, footers, and page numbers](/support/docs/headers-and-footers)) and footnotes that number themselves ([Add footnotes](/support/docs/footnotes)). Equations you type in LaTeX, with a preview as you go ([Insert and edit equations](/support/docs/equations)).

## Word files

You can bring a `.docx` in. The import keeps the text and formatting, tables, images, charts, footnotes and equations ([Import a Word document](/support/docs/import-word)). You download any document as Word, PDF or a web page. Comment threads stay behind, and a sketched chart comes out plain ([Export to Word, PDF, or HTML](/support/docs/export)).
