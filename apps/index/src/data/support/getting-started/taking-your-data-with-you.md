Your data in Eigen is yours, and you can leave with it. Most apps save what you made in a standard format that other programs open. Chat and Stickies are the exceptions. This page lists what you get from each app and links to the steps.

## Mail

Save one message at a time as an `.eml` file, with its attachments inside. See [Download an email](/support/mail/download-an-email). The web app has no button that downloads many messages at once.

To take the whole mailbox, connect a mail app such as Thunderbird over IMAP. It sees all your folders. See [Set up Eigen Mail in a mail client](/support/connect/mail-client). If your Eigen doesn't host email, your mail is still where it was.

## Contacts

Export one contact, a selection, or your whole address book as a `.vcf` file. See [Export contacts as a vCard file](/support/contacts/export-contacts).

## Calendar

Export one event or a whole calendar as an `.ics` file. See [Export a calendar or an event as a calendar file](/support/calendar/export-events).

## Documents, spreadsheets, presentations and drawings

Each app downloads a copy in the format other programs use:

- **Docs**: Word, PDF, or a web page. See [Export to Word, PDF, or HTML](/support/docs/export).
- **Sheets**: Excel, PDF, or a web page. See [Download a spreadsheet](/support/sheets/export-spreadsheet).
- **Slides**: PowerPoint, PDF, or a web page. See [Export a presentation](/support/slides/export-slides).
- **Vector**: SVG or PDF. See [Download a drawing as SVG or PDF](/support/vector/export-drawing).

## Chat and Stickies

Chat messages and Stickies boards have no download button, and they have no standard format of their own. Files you attached to a chat message or a card can be downloaded one at a time. See [Share files in chat](/support/chat/share-files) and [Attach files to a card](/support/stickies/attach-files-to-a-card). To take the chats and boards themselves, ask an admin for a backup of your account. See [If you run the server](#if-you-run-the-server).

## Files

Download any file from Drive. See [Download files](/support/drive/download-files). To work with a whole drive from your computer, connect it over WebDAV. See [Mount Drive on your computer](/support/connect/mount-drive-on-your-computer).

## If you run the server

An admin can back up one user or team from Admin, and that backup holds chats and boards too. It is a backup to restore on an Eigen server, not a file other programs open. See [Back up a user or team](/support/admin/back-up-home). The whole server is backed up with the steps in [Back up and restore the whole server](/support/self-hosting/back-up-and-restore).
