You can create an event from the sidebar or by clicking any day in the calendar, then fill in the
date, time, guests, and other details. This article covers creating an event, editing it, and
deleting it.

## Create an event

There are two ways to open the new-event form.

- Click **Create event** at the top of the sidebar.
- Click any day in the month or week view. The form opens with that date already filled in.

The **New Event** form opens as a dialog. Fill in the fields you need:

1. Type a title in the **Add title** field at the top. A title is required.
2. Set the date and, if it is a timed event, pick a start time and an end time from the dropdowns.
3. Tick **All day** if the event has no specific time. The time pickers are replaced by a date-range
   picker.
4. To make the event repeat, open the recurrence dropdown (which shows **Does not repeat** by
   default) and pick a frequency. The built-in options are daily, weekly, monthly, annually, and
   every weekday. See [Create a recurring event](/support/calendar/recurring-events) for more
   detail.
5. To invite people, type a name or email address into the **Add guests** field and click the **+**
   button or press Enter. Repeat for each guest. See
   [Invite people and manage attendees](/support/calendar/invite-people) for how invitations work.
6. Type a room name or address into **Add location** if you want one.
7. Type any notes into **Add description**.
8. If you have more than one calendar, a calendar picker appears at the bottom. Choose which
   calendar the event belongs to.
9. Click **Save**.

## Edit an event

1. Click the event in the calendar. A detail panel opens showing the time, location, description,
   and any guests.
2. Click the pencil icon in the bottom-left corner of the panel. The **Edit Event** dialog opens
   with all the same fields.
3. Make your changes, then click **Save**.

### Editing a recurring event

When you save changes to a recurring event, Calendar asks which occurrences to update:

- **This event**: changes this occurrence only. Future and past ones stay the same.
- **This and following events**: changes this occurrence and all that come after it.
- **All events in series**: changes every occurrence of the recurring event.

Choose the option that matches what you want, then click **OK**.

## Delete an event

1. Click the event to open its detail panel.
2. Click the bin icon in the bottom-left corner.
3. Confirm the deletion. For recurring events, Calendar asks the same scope question as when
   editing: you can remove this occurrence, this and following, or the whole series.

<div class="eigen-callout">

Deleting an event you organised removes it for you. If you invited other people, they will see their
copy of the event cancelled. To remove only your copy of a shared event you were invited to, decline
it from the [Respond to an invitation](/support/calendar/respond-to-invitation) flow instead.

</div>
