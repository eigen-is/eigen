You can download a presentation as a PowerPoint file, a PDF, or a self-contained web page. All three include every slide and the images you have added. In Drive, right-click the presentation (or click the **⋮** button next to it) and point to **Download** to get the same formats without opening it.

## Export to PowerPoint

Each slide becomes one slide in the PowerPoint file, with its text, shapes, lines, arrows, images, and background. The slides are the size of your presentation's, and text keeps its size in points. You can open and edit it in PowerPoint, Google Slides, or LibreOffice Impress.

1. Open the presentation in Slides.
2. Click **File** in the toolbar.
3. Point to **Download** in the menu.
4. Click **Microsoft PowerPoint (.pptx)**.

A few things look different in the PowerPoint file:

- A chart arrives as a PowerPoint chart with its numbers, kept the way PowerPoint keeps a chart's data. A rotated chart sits upright, and a see-through one is drawn solid.
- A WebP image stays a WebP, which Microsoft 365 shows but PowerPoint 2016 and 2019 can't.
- A **Hachure**, **Cross-hatch**, or **Zigzag** fill becomes solid, and every object draws with clean lines, as the **Architect** sketch style does.
- A quote keeps its indent but loses the bar along its left edge.
- The file names Eigen's fonts but doesn't include them. PowerPoint shows them only on a computer that has them installed, so PowerPoint for the web shows a similar font instead. Google Slides has Inter, Source Serif 4, and JetBrains Mono, and shows a similar font in place of Excalifont.

## Export to PDF

Each slide becomes one page in the PDF, the size of your slides. In a new presentation, 13.33 inches wide, that is 338.67 mm × 190.5 mm for 16:9, or 338.67 mm × 254 mm for 4:3. A presentation converted from PowerPoint prints at the file's own width.

1. Open the presentation in Slides.
2. Click **File** in the toolbar.
3. Point to **Download** in the menu.
4. Click **PDF (.pdf)**.

A progress dialog appears while the file is generated. When it is ready, the file downloads automatically to your browser's default download folder.

## Export as a web page

The web page export produces a single `.html` file with all slides laid out on one page. Images are embedded directly in the file, so it opens in any browser without needing an internet connection.

1. Open the presentation in Slides.
2. Click **File** in the toolbar.
3. Point to **Download** in the menu.
4. Click **Web Page (.html)**.

The file downloads in the same way as the PDF export.
