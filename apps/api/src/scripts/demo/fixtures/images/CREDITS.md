# Demo festival photo credits

The photos below are committed as build-time fixtures and uploaded into the demo team
drive's `images/` folder through Eigen's real upload path by `seed-demo.ts`, so the
self-hosted demo never fetches them at view time. All are resized to a 2000px long edge
and re-encoded as WebP.

Two groups, two licenses:

- The five site photos are **Reinder Nijhoff**'s own work (the project maintainer), used

  [Unsplash License](https://unsplash.com/license) (free to use; attribution appreciated,
  not required).
